# Fictional portrait lineup

Asset: `ai-portrait-lineup-v2.png` (1882 × 836 pixels), created on 14 September 2026
using the built-in OpenAI image-generation tool in edit mode. The exact edit
prompt is preserved in `generation-prompt.txt`. Its reference was the first
generated lineup, `ai-portrait-lineup.png`, preserved in Git commit
`52cd5977d11a032535329441205653345ad1898c`. The selected output is copied unchanged;
there is no subsequent recolouring, skin retouching or image-file cropping.

The user explicitly chose a homogeneous generated lineup with two fictional
portraits for each of the six skin-type rows. A single contact sheet gives all
twelve portraits the same framing, backdrop and lighting. Six columns progress
from very fair to deep brown; each contains two distinct invented adults with
different fictional family-background inspirations and comparable skin lightness.
The pairs no longer repeat the same general appearance in two genders. Gender
varies independently, with two women in the first column and two men in the
second. Ethnic or geographic names in the casting brief are creative directions
for fictional characters, not scientific assignments or labels shown to visitors.
Backgrounds recur across several tone bands to avoid a one-to-one mapping of
ethnicity to skin tone. Neither ethnicity nor a generated face establishes a
clinical phototype.

The UI displays the complete portrait tiles, two per hover/tap card, through SVG
viewBoxes. Each tile is one sixth of the image width by half its height
(approximately 313.67 × 418 source pixels), displayed in a 3:4 frame without
additional zoom. Column x positions are computed from the image width; row y
positions are 0 and 418. No image describes a real person or research participant.

Every card prominently states **AI-generated illustrations**, localized into
French and German. The illustrations communicate broad skin-tone descriptions,
not clinically established phototypes, a calibrated colour scale, an individual
UV tolerance or the participants behind the SED data. A person's phototype also
depends on their burning and tanning response.

[DermNet's Fitzpatrick skin-phototype description](https://dermnetnz.org/topics/skin-phototype)
supports the explanatory text only. DermNet did not supply, label, validate or
endorse these generated portraits. The numerical dose chart continues to cite
its existing scientific sources independently.

The previous Minho/Mantri images and celebrity photographs have been removed
from the site's public assets. No third-party photograph is used in this lineup;
no third-party photo licence or clinical-study attribution is claimed for it.
